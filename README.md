# DollView

Windows용 이미지·시퀀스·PDF·영상·3D 모델 뷰어. 한국어/영어, 어두운/밝은/사용자 색상 테마를 지원합니다.

## 설치와 파일 연결

Windows 10/11 64비트, .NET Framework 4.8 이상이 필요합니다.

Windows 파일 탐색기에서 EXR·PSD·HDR·TGA의 내용을 보려면 폴더의 **보기 → 큰 아이콘**을 선택하세요. 설치 시 **Windows 탐색기에 EXR, PSD, HDR, TGA 썸네일 표시**가 기본 선택됩니다. 기존 버전에서 업데이트했거나 휴대용 ZIP을 사용하는 경우 **설정 → 파일 연결 → Windows 탐색기 썸네일**을 켜세요. 같은 위치에서 끄면 이전 썸네일 설정이 복원됩니다.

FBX·GLB·glTF·OBJ·STL은 **설정 → 파일 연결 → Windows 탐색기 3D 모델 썸네일**에서 별도로 켤 수 있습니다. 설치판의 3D 썸네일 옵션은 기본 선택됩니다. 미리보기에는 모델의 형상과 기본 재질색이 표시됩니다. 외부 버퍼를 쓰는 glTF는 `.bin` 파일을 모델 폴더 안의 원래 상대 경로에 두세요.

Windows 탐색기에서 DollView에 연결된 이미지의 미리보기 오른쪽 아래에 DollView 로고가 표시됩니다. 3D 모델에는 로고 위에 **3D**가 함께 표시됩니다.

- **설치판**은 `DollView-Setup-<버전>-x64.exe`입니다. 설치 중 파일 형식 묶음에서 **이미지와 PDF**, **영상만**, **이미지, PDF와 영상**, **3D 모델만** 또는 **모든 형식**을 고를 수 있습니다. 일부 확장자를 제외하거나 **모두 해제**한 후 설치할 수도 있습니다.
- **휴대용**은 `DollView-<버전>-win-x64.zip`입니다. 압축을 모두 풀고 안에 있는 `DollView.exe`를 실행하세요. 두 배포본 모두 앱의 **업데이트** 버튼을 사용할 수 있습니다. [GitHub 배포 페이지](https://github.com/trackk81/LumaView/releases/latest)

설치 후에도 **설정 → 파일 연결**에서 **이미지·PDF**, **영상**, **3D 모델** 버튼으로 여러 형식을 함께 선택하고 **선택한 형식 연결**을 누를 수 있습니다. 이미 모두 체크된 묶음을 다시 누르면 해당 묶음이 해제됩니다. Windows 기본 앱 화면에서 원하는 확장자의 기본 앱으로 DollView를 선택하세요. Windows 버전에 따라 각 확장자를 따로 확인해야 합니다. 휴대용 폴더를 옮겼다면 새 위치에서 다시 등록하세요.

다른 PC에서 3D 보기용 WebView2와 파일 연결을 함께 준비하려면 **설정 → 구성 요소 → 다운로드 및 연결**을 누르세요. WebView2가 필요하면 Microsoft 설치 프로그램의 서명을 검증하고 설치합니다. 이어서 Windows 기본 앱 설정이 열립니다. 지원되는 Windows 11에서는 앱별 설정으로 이동하며, Windows 10에서는 기본 앱 목록에서 DollView를 선택해야 할 수 있습니다.

기본 연결 대상은 지원 형식 전체입니다. 일부만 연결하려면 먼저 **파일 연결** 탭에서 확장자를 체크하세요. **파일 연결도 함께 설정**을 해제하면 구성 요소만 준비합니다. 영상 엔진·이미지 코덱·HDR 맵은 ZIP에 포함되어 별도 설치가 필요 없으며, 구성 요소 탭에서 포함 여부도 확인합니다. 누락된 배포 파일은 ZIP 전체를 다시 압축 해제하세요.

WebView2 다운로드·설치에는 인터넷이 필요하며 회사 PC의 설치 정책에 따라 제한될 수 있습니다. 실패하면 이유를 표시하고 재시도할 수 있습니다. 앱 실행 자체에 필요한 .NET Framework 4.8은 미리 설치되어 있어야 합니다.

설정과 캐시는 사용자 프로필에 보관하므로 설치판과 휴대용에서 기존 설정을 사용합니다.

## 업데이트

현재 실행 버전은 창 제목 앞쪽과 전체화면 상단에 표시됩니다. 일반 탐색 화면에서 **설정 오른쪽의 업데이트** 버튼을 누르면 **현재 실행 버전**과 **GitHub 최신 정식 버전**을 함께 확인할 수 있습니다. 새 버전을 승인하면 ZIP 다운로드 → SHA-256·압축 경로·필수 파일·실행 파일 버전 검증 → 앱 종료 → 현재 폴더의 프로그램 파일 교체 → 자동 재실행까지 진행합니다. 초안과 사전 릴리스는 업데이트 대상에서 제외합니다.

교체 전 백업을 만들며 파일 교체 또는 새 버전 시작에 실패하면 이전 버전을 복구합니다. 사용자 설정과 배포 파일 외의 파일은 유지합니다. 백업과 결과는 `%LocalAppData%\LumaView\Updates`에 보관합니다. 프로그램 폴더에 쓰기 권한이 없으면 종료 전에 안내하며, 관리자 권한으로 실행한 뒤 다시 시도할 수 있습니다. 같은 경로의 다른 LumaView 창은 정상 종료를 요청하고, 종료되지 않으면 업데이트를 중단합니다.

같은 버전이면 ‘최신 버전입니다’, 실행 버전이 더 높으면 GitHub 공개 버전보다 새롭다고 표시합니다. 공개 릴리스가 없는 경우와 네트워크 등으로 확인하지 못한 경우도 구분합니다. 실패 시 확인된 버전 정보를 유지하며 GitHub 릴리스 페이지를 열 수 있습니다. 프로그램은 아직 코드 서명되지 않았습니다. **0.2.3 이하에서 처음 한 번은 앱을 종료하고 최신 ZIP 전체를 기존 폴더에 덮어쓴 뒤 실행하세요.** 0.2.4부터 자동 적용 기능을 포함합니다.

## 화면 구성

메인 화면은 작업 버튼과 폴더 경로를 분리하고, 이미지 목록은 카드 형태로 표시합니다. 설정은 왼쪽 메뉴에서 일반·구성 요소·파일 연결을 선택하는 구조입니다. 설정 창은 크기를 조절할 수 있으며, 좁은 창에서는 내용이 세로로 스크롤되고 저장·닫기 버튼은 하단에 유지됩니다.

버튼은 글자 길이에 맞춰 크기가 정해지고, 안내문과 오류 메시지는 자동으로 줄바꿈됩니다. 한국어·영어 및 어두운·밝은·사용자 색상 테마를 지원합니다. 언어와 테마는 저장을 누르면 적용됩니다.

## 주요 기능

- 왼쪽 폴더 탐색기와 현재 폴더의 이미지/영상 미리보기. 더블클릭하면 전체화면.
- 이미지 확대·회전·반전, 투명 배경 색/체크 크기, 상세 정보, 슬라이드쇼.
- 창 모드와 전체화면에서 휠을 돌리거나 마우스 가운데 버튼을 누른 채 위아래로 끌면 같은 폴더의 이미지와 영상을 파일명 순서로 넘깁니다. 위로는 이전 파일, 아래로는 다음 파일입니다. 오른쪽 사이드바는 현재 파일을 가운데에 두고 앞뒤 최대 다섯 개의 썸네일을 표시합니다. 조작을 멈추면 약 1.5초 뒤부터 서서히 사라집니다. 상단의 **사이드바** 버튼으로 표시를 켜거나 끌 수 있습니다.
- PDF는 탐색기에 파일 하나로 표시됩니다. 열면 오른쪽 사이드바에 페이지 미리보기가 펼쳐집니다. 휠로 마지막 페이지를 넘기면 다음 이미지나 영상으로 이동하고, 반대 방향에서는 이전 PDF의 마지막 페이지부터 볼 수 있습니다. SQ 묶기를 켜면 시퀀스도 열 때 개별 프레임이 펼쳐집니다.
- 탐색기나 이미지 뷰어 상단의 프린터 아이콘 또는 **Ctrl+P**로 인쇄합니다. PDF는 전체·현재 페이지·페이지 범위를, 탐색기의 SQ 묶음은 전체·프레임 범위를 선택할 수 있습니다. 뷰어에서 시퀀스를 인쇄하면 현재 프레임 한 장을 인쇄합니다.
- 탐색창에서 시퀀스를 SQ 항목 하나로 묶습니다. 각 프레임은 일반 이미지 뷰어에서 열리며 상세 정보에 원본 해상도가 표시됩니다.
- 영상은 내장 mpv/FFmpeg 엔진으로 재생합니다. GPU 디코딩 자동 선택과 소프트웨어 디코딩 대체를 사용하며 Windows 코덱 팩은 필요하지 않습니다. 탐색바는 클릭한 시점으로 바로 이동하고 드래그 중 최신 위치를 우선 처리합니다. D/F는 실제 디코더 프레임 단위로 앞뒤 이동하며 가변 FPS 영상도 지원합니다. 역방향 이동은 키프레임 간격에 따라 지연될 수 있습니다. 영상 썸네일은 Windows 셸 기능을 사용합니다.
- 3D 상단 **렌더링 효과**: 기본 / 사실적 / 툰·외곽선 / 시네마틱·블룸 프리셋. 그림자, 툰, 외곽선, 블룸 개별 선택 및 노출·대비·채도 조절. Three.js/WebGL 실시간 GPU 렌더링이며 Blender Eevee 엔진 자체는 아닙니다. 그림자는 전용 주광원 기준이고 환경 반사는 선택한 HDR 스카이돔을 사용합니다. 설정은 현재 뷰포트에 적용됩니다.
- **렌더링 효과 → HDR 스카이돔**: Poly Haven 2K HDRI 4종(소프트박스 스튜디오, 콘트라스트 스튜디오, 베니스 노을, 숲속 자연광)을 오프라인으로 제공합니다. 이미지 선택, 0–360° 회전, 조명 밝기, 배경 표시·흐림·밝기를 조절합니다. Shift + 좌우 드래그로 모델을 움직이지 않고 돔을 회전할 수 있습니다. 배경을 숨겨도 조명과 반사는 유지됩니다. 내 Radiance `.hdr` 파일도 불러올 수 있습니다(최대 128MB, 8192×4096; GPU 제한에 따라 더 작을 수 있음). 플랫/툰 재질에서는 HDR 조명 효과가 제한되며 그림자는 별도 주광원 기준입니다.
- OBJ/MTL, GLB/glTF, STL, FBX의 정적 3D 보기. 플랫 컬러, SSAO, 스카이돔, 포인트 라이트 색/강도/이동.
- 전체화면 메뉴 자동 숨김, 핀 고정, 오른쪽 위 종료 버튼. 메뉴가 있는 상단 영역에 마우스를 올리면 즉시 표시되며 첫 클릭부터 동작합니다. 메뉴 밖으로 이동하면 약 2.2초 뒤 숨겨지고, 펼침 메뉴나 입력란을 사용하는 동안에는 유지됩니다.
- 복사/붙여넣기/이름 변경, 파일 연결 설정.

이미지: JPG, JPEG, PNG, BMP, GIF, TIFF, ICO, WebP, EXR, PSD/PSB, TGA, HDR, DPX, DDS. GIF/TIFF는 첫 프레임, PSD/PSB는 저장된 합성 이미지입니다. EXR/HDR은 화면용 SDR 미리보기이며 AOV·OCIO·HDR 출력은 지원하지 않습니다. FBX 애니메이션 및 제작 프로그램 전용 셰이더는 지원하지 않습니다.

## 빌드와 배포

Windows PowerShell, .NET Framework C# 컴파일러와 Windows 10 또는 11 SDK를 사용합니다. 이미지·3D 런타임은 저장소에 포함되며 영상 엔진은 아래 명령으로 고정된 빌드를 내려받고 SHA-256을 확인합니다.

```powershell
.\scripts\fetch-video-runtime.ps1
.\build.ps1 -OutputDirectory .\dist\app
.\scripts\test-release.ps1
.\scripts\test-updater.ps1
.\scripts\test-settings-interaction.ps1
.\scripts\package.ps1 -CleanPortable -IncludeInstaller
.\scripts\package.ps1
```

설정과 탐색 화면의 크기별 UI 검사는 `scripts/test-layout.ps1`로 실행할 수 있습니다.

`VERSION`은 `major.minor.patch` 형식입니다. 설치판 빌드에는 Inno Setup 6.5 이상이 필요합니다. 버전 태그를 푸시하면 설치 EXE, 휴대용 ZIP, 이전 LumaView용 호환 ZIP과 체크섬을 만들어 GitHub 릴리스 초안에 첨부합니다. 앱 내 업데이트는 ZIP을 사용합니다.

기존 전체화면 이미지/영상/시퀀스/3D 표시는 직접 실행되는 로컬 프로그램입니다. 자동 시작 업데이트 검사와 사용 기록 전송은 없으며, 업데이트 버튼을 누를 때 GitHub에 접속합니다. 구성 요소 설치를 요청하면 필요한 경우에만 Microsoft 서버에서 WebView2를 내려받습니다.
